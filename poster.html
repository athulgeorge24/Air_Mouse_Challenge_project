Air Mouse Challenge

Air Mouse Challenge is an interactive, gesture-controlled web application designed to let users play a series of fast-paced mini-games using nothing but their hands. The system uses a standard webcam and MediaPipe to track hand landmarks in real-time. Once a hand is detected, the application translates these movements into seamless on-screen navigation without the need for any physical controllers. If the user pinches their index and thumb together, a natural "click" action is triggered instead of just moving the cursor.

The application uses HTML5 Canvas and TypeScript as its core engine, allowing graphics and game logic to be rendered with high performance directly in the browser. Users can engage in various challenging mini-games, including precision-focused tasks like AirMaze. The system also provides Ranked and Casual modes based on player preference, helping users enjoy the experience whether they want to compete or just relax. A comprehensive built-in leaderboard system can also help players track high scores and foster a competitive community.

The main objective of Air Mouse Challenge is to provide an accessible, immersive digital solution for touchless entertainment, intuitive gesture recognition, real-time hand tracking, and engaging mini-game mechanics. By offering this centralized platform, it reduces reliance on traditional hardware controllers and helps push the boundaries of modern web interactions.
